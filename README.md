# PC-Builder-MasterD
Aplicación web interactiva de alto rendimiento para entusiastas del hardware. Este proyecto integra un configurador de PC inteligente ("PC Builder") con validación técnica de compatibilidad (Socket y RAM), un catálogo dinámico alimentado por JSON y una experiencia visual utilizando Three.js y animaciones avanzadas con GSAP.

Características principales:
  Landing Page 3D: Escenario interactivo desarrollado con Three.js.
  Catálogo Dinámico: Sistema de filtrado de productos mediante AJAX y Fetch API.
  Constructor Inteligente: Validación en tiempo real de compatibilidad entre componentes y cálculo de presupuesto con lógica de descuentos.
  Centro Logístico: Integración de mapas con Leaflet.js, geocodificación de direcciones y cálculo de rutas.
  Calidad de Código: HTML5 semántico totalmente validado por la W3C.
Desarrollado con Vite, JavaScript (ES6+), Bootstrap 5 y LocalStorage.
